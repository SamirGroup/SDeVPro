SDeVPro's legacy scan engine (`sdevpro/engine`) exposes a headless, machine-readable
CLI mode that any AI coding agent can drive directly — no special plugin or
external skill package required.

## Agent-Friendly Interfaces

- **Headless CLI** — `sdevpro -n` runs without the TUI and exits with `0`
  (clean), `1` (error), or `2` (vulnerabilities found).
- **Structured results** — every run writes `vulnerabilities.json`,
  `vulnerabilities.csv`, `findings.sarif` (SARIF 2.1.0), and per-finding
  Markdown under `sdevpro_runs/<run-name>/`.
- **Budget controls** — `--max-budget` and `--max-turns` give agents hard
  cost/time caps.
- **`AGENTS.md`** — the [repository's agent guide](https://github.com/SamirGroup/SDeVPro/blob/main/AGENTS.md)
  with a quick reference.

## Example Prompts

```text
Pentest this repo with SDeVPro (quick mode, $10 budget) and summarize the findings.
```

```text
Fix all critical and high findings from the last SDeVPro run, then re-scan to verify.
```

```text
Add SDeVPro security scanning to our GitHub Actions so every PR gets tested.
```

## The Telegram bot

For end users (not coding agents), SDeVPro's primary interface is the
Telegram bot (`sdevpro/telegram_bot.py`) — see the main [README](https://github.com/SamirGroup/SDeVPro#readme)
for `/scan`, `/schedule`, and GitHub-repository-scanning usage.
